Kelola Data Dashboard

Pilih tahun dan indikator di atas sebelum mengedit. Setiap kombinasi memiliki data tersendiri. Klik Simpan agar perubahan tersimpan di browser ini. Untuk memindahkan data ke komputer lain, gunakan Export/Import JSON.

▤ Import Publikasi FM dari Excel

Unggah file .xlsx atau .csv untuk memperbarui publikasi semua FM berdasarkan Kode Dosen dan Title. Tahun diambil dari kolom Scopus Year.

Excel → Dashboard

Format kolom mengikuti tabel publikasi (Author, FM Author, Kode Dosen, S/F, Dept, Kampus, First Author, Sumber paper, Bobot, Submitted, St2024, Jenis, Tipe Publikasi, Title, Scopus Year, Tanggal Pelaporan, Source title, Quartile Jurnal). Kolom dapat berbeda urutan; kolom Prodi MHS dari file lama tetap dapat dibaca, tetapi tidak ditampilkan. Jika tahun kosong, gunakan tahun yang sedang dipilih.

Judul dan Angka Ringkasan

Angka pada editor ini berlaku untuk ringkasan semua quartal. Jika memilih Q1–Q4, gunakan editor Ringkasan per Quartal di bawah untuk nilai khusus. Judul tetap dapat diedit manual.

Ringkasan per Quartal

Nilai Target dan Realisasi FM/MHS dihitung otomatis dari grafik yang memiliki label Q sesuai filter. Anda dapat mengisi nilai khusus quartal untuk menggantikan hasil otomatis. Kosongkan isian untuk menggunakan hasil perhitungan grafik. Milestone dan persentase hanya dihitung jika datanya tersedia.

Grafik per Jurusan

Untuk mengedit daftar FM dan publikasi, klik Detail pada grafik jurusan, lalu gunakan tombol Tambah / Edit / Hapus dalam tabel.
